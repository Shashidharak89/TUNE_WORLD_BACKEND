# Tune World Backend

A robust RESTful API service for **Tune World**, built with **Node.js** and **Express.js**.

---

## 🛠️ Tech Stack

- **Runtime Environment:** [Node.js](https://nodejs.org/)
- **Framework:** [Express.js](https://expressjs.com/)
- **Environment Management:** [dotenv](https://www.npmjs.com/package/dotenv)

---

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v16+ recommended) and npm installed on your system.

```bash
node -v
npm -v
```

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd tune_world_backend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env` file in the root directory:
   ```env
   PORT=9000
   NODE_ENV=development
   ```

---

## 🏃 Scripts

| Command | Description |
| :--- | :--- |
| `npm start` | Runs the production server |
| `npm run dev` | Runs the server in development mode (with nodemon if configured) |
| `npm test` | Runs the test suite |
